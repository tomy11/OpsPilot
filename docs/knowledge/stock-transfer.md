# SOP: Stock Transfer Between Branches

## When to transfer stock
Transfer stock when a branch cannot fulfil a pending order and another branch holds surplus.
Prefer the branch with the largest surplus. Never leave the source branch below its safety stock of 5 units per SKU.

## Approval rules
Every stock transfer must be approved by a manager of the requesting department before execution.
The requester cannot approve their own transfer.

## Order handling while waiting
While a transfer is pending, set the order to on_hold with a note that references the transfer.
